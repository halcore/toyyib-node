# Security

## Reporting a vulnerability

Please report security problems privately, by email to [info@halcore.app](mailto:info@halcore.app). Don't open a public issue, pull request or discussion for them.

Include what you found, how to reproduce it, and which version of `@toyyib/sdk` you used. We'll acknowledge your report, keep you updated while we fix it, and credit you when the fix is released, unless you'd rather not be named.

## Supported versions

Fixes are released for the latest `0.x` version.

## API keys

If an API key has been exposed, in a commit, a log or a browser bundle for example, contact [info@halcore.app](mailto:info@halcore.app) to have it revoked and replaced. Never put a key in an issue or pull request.
